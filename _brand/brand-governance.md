# Zeza.co.za Global Brand Governance

This repository is a Zeza.co.za public website. Its global page chrome must follow the organisation brand contract maintained in `zeza-co-za/www`.

## Required global header

Use the same global navigation and brand treatment as the main Zeza.co.za website:

- Resources
- Courses
- Shop
- Community
- Tools
- Media
- Docs
- Book a Call

The `Media` navigation item must link to `https://media.zeza.co.za/`.

For this media portal, the current page may also retain its specialist `Upload` and `Library` controls, but the global Zeza navigation and brand treatment must remain recognisable and consistent.

## Required global footer

Use the Zeza.co.za footer treatment with:

- Zeza.co.za brand mark and organisation description
- Contact details
- Legal links
- Docs link
- Media Library link
- Current copyright year

## Visual system

Use the organisation design tokens and shared assets from `zeza-co-za/www`:

- Primary brand colour: `#7c2d45`
- Secondary brand colour: `#b65f76`
- Accent gold: `#d7a84d`
- Dark text/background: `#21171c`
- Shared styles and assets wherever practical

Do not introduce unrelated themes, colours, logos, or global header/footer systems.
